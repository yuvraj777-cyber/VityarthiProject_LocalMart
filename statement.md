# LocalMart – Local Commerce Management System

## Problem

Local businesses often operate differently from standardized online
e-commerce platforms. Some businesses sell ready-to-buy products,
while others provide customized products, consultation, installation,
or other services.

Customers may find it difficult to discover local businesses,
compare their ratings and reviews, purchase available products, or
request customized services through a single platform.

LocalMart addresses this problem by providing a console-based system
that connects customers with local shops and supports both product
orders and service requests.

## Scope

The scope of LocalMart includes:

- Customer registration and login
- Shop owner registration and login
- Admin login and system monitoring
- Local shop management
- Product management
- Service management
- Product ordering
- Product stock management
- Service request management
- Appointment scheduling
- Order status management
- Service request status management
- Appointment status management
- Customer ratings and reviews
- Shop rating calculation
- In-memory data management using Java ArrayList

The current version is a Java console-based application and does not
use an external database, web interface, mobile application, or
payment gateway.

## Target Users

### 1. Customers

Customers can discover shops, view products and services, place
product orders, request services, view appointments, and provide
ratings and reviews.

### 2. Shop Owners

Shop owners can manage their shop information, add products and
services, manage product orders, process service requests, manage
appointments, and view customer reviews.

### 3. Administrator

The administrator can monitor customers, shop owners, shops, orders,
service requests, appointments, and the overall system summary.

## High-Level Features

### Customer Features

- Register and login
- View profile
- View and search shops
- Browse products
- Browse services
- Place product orders
- View orders
- Request services
- View service requests
- View appointments

- Register and login
- View shop
- Add and view products
- Add and view services
- View orders

- View service requests

### Admin Features

- Login
- View all customers
- View all shop owners

- View all orders
- View all service requests

- View system summary
